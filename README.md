# DocSnap

Updates und Lizenzverwaltung fuer DocSnap.

Dieses Repository enthaelt ausschliesslich signierte Verwaltungsdateien:

- **Releases** - die jeweils aktuelle Programmfassung und ihre Beschreibung
- **sperrliste.json** - gesperrte Rechner-Kennungen

Alle Dateien sind mit einem Ed25519-Schluessel unterschrieben. Ohne gueltige
Unterschrift werden sie vom Programm ignoriert.
